Tjänsteskrivelse Svar på motion om Visa telefonnummer vid

uppringning från Region Hallands vårdverksamheter

Förslag till beslut
Regionstyrelsen föreslår regionfullmäktige att
  bifalla motionen

Sammanfattning

I februari 2019 inkom Sverigedemokraterna med en motion där det framfördes
synpunkter på att Region Halland inte visar något telefonnummer när samtal rings ut
från vårdverksamheterna. Att inte kunna se vem det är som ringer gör att många
väljer att inte svara, vilket kan förhindra och försena när exempelvis verksamheterna
vill ha kontakt med en patient. I motionen önskas att Region Halland ser över möjliga
lösningar för att införa ett system där exempelvis ett växelnummer syns när någon
personal ringer, och dels att Region Halland snarast möjligt inför detta.

I rollen som facknämnd lämnade RGS (Regiongemensam service) ett svar till
Regionstyrelsen i maj 2019. Det konstaterades att de tekniska möjligheterna att visa

ett telefonnummer vid utringning redan finns och att det är upp till varje verksamhet
att använda möjligheten. Efter samråd med övriga förvaltningschefer framgår det att
vårdverksamheterna som berörs av motionen ställer sig bakom förslag om att
telefonnumret inte längre ska vara dolt vid utringning. Underlaget bedöms därmed
visa att motionen kan bifallas.

Bakgrund
Carita Boulwén, Sverigedemokraterna, yrkar i sin motion dels att Region Halland ser
över möjliga lösningar för att införa ett system där exempelvis ett växelnummer syns
när någon personal ringer, och dels att Region Halland snarast möjligt inför detta.

Driftnämnden för RGS skriver i sitt remissvar att Region Halland sedan slutet av 2016
har möjlighet att visa verksamhetens eget telefonnummer, samt att detta informerats
om på regionens intranät. De mottagningar som använder TeleQ har också möjlighet
att visa sitt huvudnummer, det vill säga det nummer som patienterna även ringer in
på.

Den inkomna motionen samt svaret från RGS har lämnats till övriga
förvaltningschefer för kommentar sett utifrån respektive förvaltnings förutsättningar.

Samtliga förvaltningschefer ställer sig positiva till att använda möjligheten att visa ett
telefonnummer.

Ekonomiska konsekvenser av beslutet
Beslutet bedöms inte ha några ekonomiska konsekvenser då de tekniska

möjligheterna att visa telefonnummer vid utringning redan finns inom regionen.
